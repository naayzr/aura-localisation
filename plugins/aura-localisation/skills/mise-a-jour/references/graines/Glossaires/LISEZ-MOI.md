# Glossaires
Un classeur Excel par gamme : `Glossaire_<Gamme>.xlsx`, sans numéro de version dans le nom. Onglets : Tableau de bord, Termes, CHANGELOG, Notice. AURA les crée et les tient à jour ; ne pas les garder ouverts dans Excel pendant qu'AURA travaille.

Un glossaire venu d'ailleurs (celui de la démonstration, un ancien Excel, celui d'un éditeur) ne se pose pas ici : ici, il passerait pour un second glossaire de sa gamme. Copie-le dans le dossier IMPORT, puis dis à AURA « j'ai mis [nom] dans IMPORT ».
