# Ancienne version des outils
Les sous-dossiers de `skills/` qui portent le nom d'un des 7 outils de la version 2.0 (brief-editeur, comprehension-regles, glossaire, narration-jeux, qa-coherence, relecture-multi-agents, traduction-jeux) ne servent plus : depuis la version 3.0, ces outils viennent du plugin AURA (`aura-localisation`) installé sur ton compte Claude ; ses nouvelles versions : voir `GUIDE_AURA.md`. AURA ne les lit plus.

Un AUTRE sous-dossier peut être un outil fait pour toi : il est conservé, et noté dans `Core/Outils_Perso.md`. Ne le supprime pas sans en parler à AURA.
